# Credits

Horde system and zombie artwork by Garrett McNeill, developed for Zmail at Wildcat Game Studios.

The demo includes the zombie model, texture, baked vertex animation texture and animation metadata. The horde scripts were extracted from Zmail; `docs/source-manifest.json` records their source checksums.
